# Lesson 1 (Clean): DOM & Debugging Einstieg

## Ziel
- DOM selektieren, Werte lesen, rechnen, Ausgaben schreiben
- Breakpoints setzen, Variablen inspizieren

## Schritte
1) `index.html` öffnen.
2) In VS Code Breakpoint in `script.js` beim Event-Handler setzen.
3) Mit Launch-Konfiguration "HTML-Datei im Chrome starten (Lesson 1)" starten.
4) Eingaben variieren, Werte im Debugger prüfen.
