# DOM Debug Unterrichtspaket

## Struktur
- lesson1-clean/ — funktionierendes Beispiel (Start)
- lesson2-bugs/ — gleiche Oberfläche mit eingebauten Fehlern (Übung)
- .vscode/launch.json — Startkonfigurationen für Chrome/Edge (ohne Live Server)

## Verwendung
1) Ordner in VS Code öffnen.
2) In `Run and Debug` die passende Launch-Konfiguration wählen.
3) Lesson 1 kennenlernen, Breakpoints setzen.
4) Lesson 2: Fehler mit Debugger systematisch finden (Console, Breakpoints, Watch, Call Stack).
